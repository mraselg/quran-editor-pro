WHAT THIS PROJECT IS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

"Studio Al-Qalam" is a high-precision Quranic DTP editor built with:
  - TanStack Start (React, file-based routing)
  - Zustand + zundo (state + undo/redo)
  - Tailwind CSS v4
  - react-window v2 (virtualized 1740-page list)
  - Electron (desktop app, in progress)
  - sql.js (pure-JS SQLite, no native build needed)
